# リユース検定 演習帳（ホーム画面に追加できる版）

全5章・62問の演習アプリです。iPhone と Android のどちらでも、ホーム画面に追加するとアプリのように起動し、一度開けば電波がない場所でも使えます。

## 入っているファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体 |
| `questions.json` | 問題・選択肢・正解・解説（問題の追加や修正はここだけ） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前とアイコン |
| `sw.js` | オフラインで動かすための仕組み |
| `icons/` | アイコン画像 |

## 公開のしかた（GitHub Pages・無料）

1. GitHub で新しいリポジトリを作る（例：`reuse-kentei`）
2. このフォルダの中身をすべてアップロードする（「Add file」→「Upload files」）
3. 「Settings」→「Pages」で、Branch を `main`、フォルダを `/ (root)` にして保存する
4. 数分後に表示される URL（`https://ユーザー名.github.io/reuse-kentei/`）をスタッフに共有する

無料プランの GitHub Pages は、URL を知っていれば誰でも開けます。問題はすべて社内で作ったオリジナルで、個人情報は入っていません。

## ホーム画面への追加

- **iPhone**：Safari で URL を開く →「共有」→「ホーム画面に追加」
- **Android**：Chrome で URL を開く → 右上のメニュー →「ホーム画面に追加」または「アプリをインストール」

## 問題を直す・増やすとき

1. `questions.json` を編集する（`answer` は選択肢の番号で、最初の選択肢が `0`）
2. `sw.js` の `VERSION` の日付を新しくする
3. 2つのファイルを GitHub にアップロードし直す

スタッフのアプリは、次に通信できる状態で開いたときに新しい問題に切り替わります。

## 記録について

正解記録・苦手ノート・模試の履歴は、それぞれのスマホのブラウザにだけ保存されます。機種変更やブラウザのデータ削除をすると消えます。
